# Static-review remediation — `v0.4.0..release/0.5.0`

A defect queue, not a report: every unchecked box here is work the project still owes itself.

## Provenance

Produced by a full gate-based static review (fornax `static-review` skill) plus an adversarial
contract audit over the whole `v0.4.0..HEAD` range (265 commits, 236 files): 145 code files
individually triaged (0 Red, 6 Yellow, 139 Green), the 6 Yellow files taken through the full 8-gate
ladder, and 126 contract clauses + 181 CHANGELOG/BACKLOG claims adversarially verified against
`HEAD` (falsifiers constructed live where feasible, not just read for plausibility). Full findings
detail lives in this campaign's conversation record; this file is the input to the remaining
lifecycle, not a substitute for it.

Ordering: Phase 1 (release-blocking) → Phase 2 (should-fix) → Phase 3 (documentation
reconciliation) → partial-claims batch. Within a phase, gate/contract-violation order, then
file:line.
